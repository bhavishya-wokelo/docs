## 1. Overview

The Fundraise Activity API surfaces the funding rounds that have taken place in a given industry domain. Each record shows which company raised, at what stage, from which investors, on what date, what the company does, and relevant news coverage.

This is an **asynchronous API**. Starting the workflow returns a `report_id`, which you use to track completion and export the results. See [How Async APIs work](/how-async-apis-work).

Each record includes round metadata (date, stage, amount, lead and other investors), company firmographics and business profile, and curated news. A company appears once per funding event, so you can reconstruct its full financing history by grouping on `Permalink`.

**Common use cases:**

- **Market intelligence**: track which investors are most active in a sector
- **Startup scouting**: surface early-stage companies in niche categories
- **Portfolio monitoring**: catch new funding events in categories you track

## 2. Quick Start

**Step 1: Start the workflow**

<CodeGroup>

```bash cURL
curl --location 'https://api.wokelo.ai/api/workflow_manager/start/' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "Neo databases",
    "workflow": "fundraisers_workflow",
    "workbook_name": "Neo databases",
    "advanced_settings": {
      "company_type": "all",
      "geography": ["Worldwide"],
      "transaction_funding_round_type": [],
      "employee_count": [],
      "transaction_amount_include_blanks": true,
      "transaction_date": {
        "from": "2023-10-28",
        "to": "2026-10-29"
      }
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.wokelo.ai/api/workflow_manager/start/",
    headers={
        "Authorization": "Bearer <YOUR_API_TOKEN>",
        "Content-Type": "application/json"
    },
    json={
        "topic": "Neo databases",
        "workflow": "fundraisers_workflow",
        "workbook_name": "Neo databases",
        "advanced_settings": {
            "company_type": "all",
            "geography": ["Worldwide"],
            "transaction_funding_round_type": [],
            "employee_count": [],
            "transaction_amount_include_blanks": True,
            "transaction_date": {
                "from": "2023-10-28",
                "to": "2026-10-29"
            }
        }
    }
)
print(response.json()["report_id"])
```

</CodeGroup>

The response contains a `report_id`.

**Step 2: Track completion**

Use `/api/assets/get_notebook_status/` with the `report_id` to check whether the report has completed.

**Step 3: Export results**

Once the report is complete, use `/api/assets/download_report/` with the `report_id` to export the results.

## 3. Authentication

Include a Bearer token in the `Authorization` header of every request.

```text
Authorization: Bearer <YOUR_API_TOKEN>
```

Obtain a token from the `/auth/token/` endpoint using the client id and client secret under **Account Details → API Credentials** in the Wokelo dashboard. Contact [support@wokelo.ai](mailto:support@wokelo.ai) if you do not yet have API access.

## 4. Request Reference

**Endpoint**

```text
POST https://api.wokelo.ai/api/workflow_manager/start/
```

The request body is JSON. Include `advanced_settings` in every request and send empty values (`[]`) for filters you do not want to apply. Dates use the `YYYY-MM-DD` format.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `topic` | string | **Required** | Industry topic to surface funding activity for (e.g. `"Neo databases"`). |
| `workflow` | string | **Required** | Must be `"fundraisers_workflow"`. |
| `workbook_name` | string | **Required** | Name of the workbook that holds the generated report. |
| `advanced_settings` | object | Optional | Filter parameters. All filters below live inside this object. |
| `advanced_settings.transaction_date` | object | Optional | Object with `from` and/or `to` (`YYYY-MM-DD`, inclusive). |
| `advanced_settings.transaction_funding_round_type` | string[] | Optional | Funding round types (e.g. `"Seed"`, `"Series A"`). Empty array includes all. |
| `advanced_settings.transaction_amount` | object | Optional | Object with `from` and/or `to`, in million USD. |
| `advanced_settings.transaction_amount_include_blanks` | boolean | Optional | When `true`, rounds with no disclosed amount are included. |
| `advanced_settings.company_type` | string | Optional | `"private"`, `"public"` or `"all"`. |
| `advanced_settings.geography` | string[] | Optional | `["Worldwide"]` for no restriction, or ISO country codes (e.g. `["USA", "GBR"]`). |
| `advanced_settings.employee_count` | string[] | Optional | Headcount bands. Empty array includes all. Values: `1-10`, `11-50`, `51-100`, `101-250`, `251-500`, `501-1000`, `1001-5000`, `5001-10000`, `10000+`. |

## 5. Response

### Workflow start response

```json
{
  "report_id": 117253
}
```

| Field | Type | Description |
| --- | --- | --- |
| `report_id` | integer | Unique identifier of the report. Use it to track completion and export results. |

### Report output fields

| Field | Description |
| --- | --- |
| `Permalink` | Stable company identifier. The same value repeats across a company's rounds. |
| `Funding Date` | `YYYY-MM-DD`. |
| `Funding Stage` | Round classification, e.g. `Pre-seed`, `Seed`, `Series A` to `Series J`, `Angel round`, `Convertible note`, `Grant`, `Debt-Funded`, `Private equity round`, `Corporate-Funded`, `Non-Equity Assistance`, `Undisclosed`. |
| `Funding Amount ($M)` | Round size. Null when undisclosed. |
| `Lead Investor(s)`, `Other Investor(s)` | Arrays of investor names. Null when none were identified. |
| `Name`, `Website` | Company that raised and its primary domain. |
| `HQ City`, `HQ Country`, `HQ Continent`, `Founded` | Headquarters location and founding year. |
| `Employees (Crunchbase)`, `Employees (LinkedIn)` | Headcount band and numeric headcount. |
| `Product Category`, `Core Offering`, `Product Catalog` | Product category, AI-generated description and key products. |
| `News` | Unstructured text of news summaries, each followed by a source URL. Null when no coverage was indexed. |
