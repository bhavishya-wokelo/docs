## 1. Overview

The M&A Activity API surfaces the M&A transactions that have taken place in a given industry domain. Each record shows who acquired whom, at what price, on what date, what the target does, and relevant news coverage.

This is an **asynchronous API**. Starting the workflow returns a `report_id`, which you use to track completion and export the results. See [How Async APIs work](/how-async-apis-work).

Each transaction includes deal metadata (dates, status, amount), the acquirer profile, target firmographics and business profile, and curated news with source URLs.

**Common use cases:**

- **Competitive intelligence**: track which acquirers are most active in a sector
- **Due diligence**: assemble precedent transactions for a category or acquirer
- **Portfolio monitoring**: catch new deals in categories you track

## 2. Quick Start

**Step 1: Start the workflow**

<CodeGroup>

```bash cURL
curl --location 'https://api.wokelo.ai/api/workflow_manager/start/' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "HVAC in US",
    "workflow": "acquisition_workflow",
    "workbook_name": "HVAC in US",
    "advanced_settings": {
      "company_type": "all",
      "geography": ["Worldwide"],
      "funding_stage": [],
      "employee_count": [],
      "total_funding_include_blanks": true,
      "transaction_date": {
        "from": "2023-10-28",
        "to": "2026-10-29"
      },
      "transaction_status": [],
      "transaction_amount_include_blanks": true
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.wokelo.ai/api/workflow_manager/start/",
    headers={
        "Authorization": "Bearer <YOUR_API_TOKEN>",
        "Content-Type": "application/json"
    },
    json={
        "topic": "HVAC in US",
        "workflow": "acquisition_workflow",
        "workbook_name": "HVAC in US",
        "advanced_settings": {
            "company_type": "all",
            "geography": ["Worldwide"],
            "funding_stage": [],
            "employee_count": [],
            "total_funding_include_blanks": True,
            "transaction_date": {
                "from": "2023-10-28",
                "to": "2026-10-29"
            },
            "transaction_status": [],
            "transaction_amount_include_blanks": True
        }
    }
)
print(response.json()["report_id"])
```

</CodeGroup>

The response contains a `report_id`.

**Step 2: Track completion**

Use `/api/assets/get_notebook_status/` with the `report_id` to check whether the report has completed.

**Step 3: Export results**

Once the report is complete, use `/api/assets/download_report/` with the `report_id` to export the results.

Include a Bearer token in the `Authorization` header of every request.


Obtain a token from the `/auth/token/` endpoint using the client id and client secret under **Account Details → API Credentials** in the Wokelo dashboard. Contact [support@wokelo.ai](mailto:support@wokelo.ai) if you do not yet have API access.

## 4. Request Reference

**Endpoint**

```text
POST https://api.wokelo.ai/api/workflow_manager/start/
```

The request body is JSON. Include `advanced_settings` in every request and send empty values (`[]`) for filters you do not want to apply. Dates use the `YYYY-MM-DD` format.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `topic` | string | **Required** | Industry topic to surface M&A transactions for (e.g. `"HVAC in US"`). |
| `workflow` | string | **Required** | Must be `"acquisition_workflow"`. |
| `workbook_name` | string | **Required** | Name of the workbook that holds the generated report. |
| `advanced_settings` | object | Optional | Filter parameters. All filters below live inside this object. |
| `advanced_settings.transaction_date` | object | Optional | Object with `from` and/or `to` (`YYYY-MM-DD`, inclusive). |
| `advanced_settings.transaction_status` | string[] | Optional | `"completed"`, `"announced"`. Empty array includes all statuses. |
| `advanced_settings.transaction_amount` | object | Optional | Object with `from` and/or `to`, in million USD. |
| `advanced_settings.transaction_amount_include_blanks` | boolean | Optional | When `true`, transactions with no disclosed amount are included. |
| `advanced_settings.company_type` | string | Optional | `"private"`, `"public"` or `"all"`. |
| `advanced_settings.geography` | string[] | Optional | `["Worldwide"]` for no restriction, or ISO country codes (e.g. `["USA", "GBR"]`). |
| `advanced_settings.founded_year` | object | Optional | Object with `from` and/or `to` (integer years, inclusive). |
| `advanced_settings.employee_count` | string[] | Optional | Headcount bands. Empty array includes all. Values: `1-10`, `11-50`, `51-100`, `101-250`, `251-500`, `501-1000`, `1001-5000`, `5001-10000`, `10000+`. |
| `advanced_settings.total_funding` | object | Optional | Target total funding. Object with `from` and/or `to`, in million USD. |
| `advanced_settings.total_funding_include_blanks` | boolean | Optional | When `true`, companies with no reported total funding are included. |
| `advanced_settings.funding_stage` | string[] | Optional | Empty array includes all. Values: `Non-Equity Assistance`, `Angel round`, `Pre-seed`, `Seed`, `Series A` to `Series J`, `Corporate-Funded`, `Debt-Funded`, `Private equity round`, `Others`. |

## 5. Response

### Workflow start response

```json
{
  "report_id": 117253
}
```

| Field | Type | Description |
| --- | --- | --- |
| `report_id` | integer | Unique identifier of the report. Use it to track completion and export results. |

### Report output fields

| Field | Description |
| --- | --- |
| `Permalink` | Stable unique identifier for the transaction. Use it as a primary key. |
| `Deal Date (Announced)`, `Deal Completion Date` | `YYYY-MM-DD`. Completion date is null for pending deals. |
| `Deal Status` | `Complete` or `Pending`. |
| `Deal Amount ($M)` | Transaction value. Null when undisclosed. |
| `Acquirer Name`, `Acquirer Website`, `Acquirer Type` | Acquirer details. Type is `Strategic` or `Institutional`. |
| `Target Name`, `Target Website` | Acquired company and its primary domain. |
| `Target HQ City`, `Target HQ Country`, `Target HQ Continent`, `Target Founded` | Target headquarters and founding year. |
| `Target Employees (Crunchbase)`, `Target Employees (LinkedIn)` | Headcount band and numeric headcount. |
| `Target Product Category`, `Target Core Offering`, `Target Product Catalog` | Target product category, AI-generated description and key products. |
| `News` | Unstructured text of news summaries, each followed by a source URL. Null when no coverage was indexed. |
