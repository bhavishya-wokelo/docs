## Overview

Wokelo APIs in the **Discovery** and **Workflow Automation** categories operate asynchronously. These operations involve deep AI research, large-scale data enrichment and multi-source synthesis, so they can take several minutes to complete. Rather than keeping your HTTP connection open for that entire duration, Wokelo uses a **Submit, Check Status, Download** pattern.

Every async API returns a `report_id` as soon as the request is accepted. This ID is your handle for everything that follows. Your integration stays non-blocking: submit a job, move on, and download the results when they are ready.

## Why Asynchronous?

Wokelo produces intelligence at investment-grade quality, resolving entities, deduplicating signals across sources and running structured AI workflows. This depth takes time, and a synchronous API would need to hold a connection open for the full run.

The async pattern lets you:

- **Decouple submission from retrieval**: start a job and handle the result whenever it is ready
- **Handle long-running tasks reliably**: no timeout failures on deep research jobs
- **Run multiple requests in parallel**: submit many jobs at once and track each by its `report_id`
- **Integrate cleanly into pipelines**: queue results, trigger downstream workflows, or store outputs on completion

## The Three-Step Flow

```text
1. SUBMIT   POST /api/workflow_manager/start/       →  returns report_id
2. STATUS   GET  /api/assets/get_notebook_status/   →  returns status
3. DOWNLOAD POST /api/assets/download_report/       →  returns the report
```

### Step 1: Submit a Request

Call the relevant API endpoint with your parameters. The API returns immediately with a `report_id`.

**Example: starting a Market Map workflow**

```bash
curl --request POST \
  --url https://api.wokelo.ai/api/workflow_manager/start/ \
  --header 'Authorization: Bearer YOUR_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "warehouse automation",
    "workflow": "agentic_mm",
    "workbook_name": "warehouse automation",
    "advanced_settings": {
      "detailed_query": "warehouse automation",
      "companies": [],
      "company_type": "all",
      "geography": ["Worldwide"],
      "employee_count": [],
      "funding_stage": [],
      "total_funding_include_blanks": true
    }
  }'
```

**Response:**

```json
{
  "report_id": 117253
}
```

> **Save the `report_id`.** You need it in Steps 2 and 3.

### Step 2: Check Report Status

After submitting, periodically call the **Get Report Status** endpoint with your `report_id`.

```text
GET /api/assets/get_notebook_status/?report_id={your_report_id}
```

**Example:**

```bash
curl --request GET \
  --url 'https://api.wokelo.ai/api/assets/get_notebook_status/?report_id=117253' \
  --header 'Authorization: Bearer YOUR_TOKEN'
```

**Response:**

```json
{
  "report_id": 117253,
  "status": "Processing",
  "title": "warehouse automation"
}
```

#### Status values

| Status | Meaning |
| --- | --- |
| `Queued` | The report has been received and is waiting to be processed. |
| `Processing` | The report is actively being generated. |
| `Delayed` | The report is taking longer than expected. |
| `Completed` | Generation finished successfully. The report is ready to download. |
| `Exported` | The report has been exported. |
| `No Data Found` | No data was found for the request. |

Poll with a gradually increasing interval rather than a tight loop. Polling more often does not speed up results.

#### Polling code examples

```python
# Python: polling with exponential backoff
import requests
import time

headers = {"Authorization": "Bearer YOUR_TOKEN"}
report_id = 117253
interval = 10  # seconds

while True:
    response = requests.get(
        "https://api.wokelo.ai/api/assets/get_notebook_status/",
        headers=headers,
        params={"report_id": report_id}
    )
    status = response.json()["status"]
    print(f"Status: {status}")

    if status in ("Completed", "Exported"):
        break
    if status == "No Data Found":
        raise Exception(f"No data found for report {report_id}")

    time.sleep(interval)
    interval = min(interval * 1.5, 60)  # cap at 60 seconds
```

```javascript
// JavaScript: async polling loop
async function pollForCompletion(reportId, token) {
  const url = `https://api.wokelo.ai/api/assets/get_notebook_status/?report_id=${reportId}`;
  const headers = { Authorization: `Bearer ${token}` };
  let interval = 10000; // start at 10s

  while (true) {
    const res = await fetch(url, { headers });
    const data = await res.json();
    console.log("Status:", data.status);

    if (data.status === "Completed" || data.status === "Exported") return data;
    if (data.status === "No Data Found") throw new Error("No data found");

    await new Promise((resolve) => setTimeout(resolve, interval));
    interval = Math.min(interval * 1.5, 60000); // cap at 60s
  }
}
```

```go
// Go: polling loop with sleep
package main

import (
    "encoding/json"
    "fmt"
    "io"
    "net/http"
    "time"
)

func pollStatus(reportID, token string) {
    interval := 10 * time.Second
    for {
        req, _ := http.NewRequest("GET",
            "https://api.wokelo.ai/api/assets/get_notebook_status/?report_id="+reportID, nil)
        req.Header.Set("Authorization", "Bearer "+token)
        resp, _ := http.DefaultClient.Do(req)
        body, _ := io.ReadAll(resp.Body)
        resp.Body.Close()

        var result map[string]interface{}
        json.Unmarshal(body, &result)
        status := result["status"].(string)
        fmt.Println("Status:", status)

        if status == "Completed" || status == "Exported" || status == "No Data Found" {
            fmt.Println(string(body))
            return
        }
        time.Sleep(interval)
        if interval < 60*time.Second {
            interval = time.Duration(float64(interval) * 1.5)
        }
    }
}
```

### Step 3: Download the Report

Once the status is `Completed`, export the report with the **Download Report** endpoint. Pass the `report_id` and the export format in the request body.

```text
POST /api/assets/download_report/
```

| Body parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `report_id` | integer | Yes | Id of the report to export. |
| `file_type` | string | Yes | Export format. One of `"pdf"`, `"docx"`, `"json"`. |

**Example:**

```bash
curl --request POST \
  --url https://api.wokelo.ai/api/assets/download_report/ \
  --header 'Authorization: Bearer YOUR_TOKEN' \
  --header 'Content-Type: application/json' \
  --output report.pdf \
  --data '{
    "report_id": 117253,
    "file_type": "pdf"
  }'
```

The response is the report file in the requested format.

### Complete End-to-End Example

The following Python example shows the full Submit, Status, Download cycle for a Market Map request:

```python
import requests
import time

BASE_URL = "https://api.wokelo.ai"
HEADERS = {
    "Authorization": "Bearer YOUR_TOKEN",
    "Content-Type": "application/json"
}

# STEP 1: Submit
submit = requests.post(
    f"{BASE_URL}/api/workflow_manager/start/",
    headers=HEADERS,
    json={
        "topic": "warehouse automation",
        "workflow": "agentic_mm",
        "workbook_name": "warehouse automation",
        "advanced_settings": {
            "detailed_query": "warehouse automation",
            "companies": [],
            "company_type": "all",
            "geography": ["Worldwide"],
            "employee_count": [],
            "funding_stage": [],
            "total_funding_include_blanks": True
        }
    }
)
report_id = submit.json()["report_id"]
print(f"Submitted. report_id: {report_id}")

# STEP 2: Check status
interval = 15
while True:
    status = requests.get(
        f"{BASE_URL}/api/assets/get_notebook_status/",
        headers=HEADERS,
        params={"report_id": report_id}
    ).json()["status"]
    print(f"Status: {status}")

    if status in ("Completed", "Exported"):
        break
    if status == "No Data Found":
        raise Exception("No data found.")

    time.sleep(interval)
    interval = min(interval * 1.5, 60)

# STEP 3: Download
download = requests.post(
    f"{BASE_URL}/api/assets/download_report/",
    headers=HEADERS,
    json={"report_id": report_id, "file_type": "pdf"}
)
with open("report.pdf", "wb") as f:
    f.write(download.content)
print("Report saved to report.pdf")
```
