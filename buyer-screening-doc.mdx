## 1. Overview

The Buyer Screening API identifies and scores potential acquirers for a defined target company. Given a target and strategic criteria, the AI pipeline evaluates each candidate buyer and returns a ranked list with deal scores, synergy commentary and financial profiles.

This is an **asynchronous API**. Starting the workflow returns a `report_id`, which you use to track completion and export the results. See [How Async APIs work](/how-async-apis-work).

Each buyer receives an `Overall Score` (1 to 10) and four sub-scores: `Deal Feasibility Score`, `Product Synergy Score`, `Deal Precedent Score` and `Synergy Potential Score`, each with a written rationale, plus a `Commentary` summarising the deal thesis.

**Common use cases:**

- **Sell-side advisory**: generate a scored buyer universe for a sale process
- **Private equity exits**: screen strategic and financial buyers for portfolio companies
- **Corporate development**: identify acquirers for subsidiaries or divestitures

## 2. Quick Start

**Step 1: Start the workflow**

<CodeGroup>

```bash cURL
curl --location 'https://api.wokelo.ai/api/workflow_manager/start/' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "Civil Engineering Infrastructure Services",
    "workflow": "buyer_analysis",
    "workbook_name": "Ulteig Buyers",
    "advanced_settings": {
      "target": "ulteig",
      "detailed_query": "Civil Engineering Infrastructure Services",
      "companies": [],
      "buyer_type": [],
      "company_type": "all",
      "geography": ["Worldwide"]
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.wokelo.ai/api/workflow_manager/start/",
    headers={
        "Authorization": "Bearer <YOUR_API_TOKEN>",
        "Content-Type": "application/json"
    },
    json={
        "topic": "Civil Engineering Infrastructure Services",
        "workflow": "buyer_analysis",
        "workbook_name": "Ulteig Buyers",
        "advanced_settings": {
            "target": "ulteig",
            "detailed_query": "Civil Engineering Infrastructure Services",
            "companies": [],
            "buyer_type": [],
            "company_type": "all",
            "geography": ["Worldwide"]
        }
    }
)
print(response.json()["report_id"])
```

</CodeGroup>

The response contains a `report_id`.

**Step 2: Track completion**

Use `/api/assets/get_notebook_status/` with the `report_id` to check whether the report has completed.

**Step 3: Export results**

Once the report is complete, use `/api/assets/download_report/` with the `report_id` to export the results.

## 3. Authentication

Include a Bearer token in the `Authorization` header of every request.

```text
Authorization: Bearer <YOUR_API_TOKEN>
```

Obtain a token from the `/auth/token/` endpoint using the client id and client secret under **Account Details → API Credentials** in the Wokelo dashboard. Contact [support@wokelo.ai](mailto:support@wokelo.ai) if you do not yet have API access.

<Warning>

## 4. Request Reference

**Endpoint**

```text
POST https://api.wokelo.ai/api/workflow_manager/start/
```

The request body is JSON. Include `advanced_settings` in every request and send empty values (`""`, `[]`) for filters you do not want to apply.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `topic` | string | **Required** | The sector or theme describing the target's business (e.g. `"Civil Engineering Infrastructure Services"`). |
| `workflow` | string | **Required** | Must be `"buyer_analysis"`. |
| `workbook_name` | string | **Required** | Name of the workbook that holds the generated report. |
| `advanced_settings` | object | **Required** | Target and filter parameters. All fields below live inside this object. |
| `advanced_settings.target` | string | **Required** | Permalink or full URL of the target company being sold (e.g. `"ulteig"`). |
| `advanced_settings.detailed_query` | string | Optional | A descriptive query that refines the buyer search scope and strategic criteria. |
| `advanced_settings.companies` | string[] | Optional | Permalinks or full URLs of representative companies to anchor the buyer search. |
| `advanced_settings.buyer_type` | string[] | Optional | `"strategic"`, `"financial"`. Empty array includes all buyer types. |
| `advanced_settings.company_type` | string | Optional | `"private"`, `"public"` or `"all"`. |
| `advanced_settings.geography` | string[] | Optional | `["Worldwide"]` for no restriction, or ISO country codes (e.g. `["USA", "GBR"]`). |

## 5. Response

### Workflow start response

```json
{
  "report_id": 117253
}
```

| Field | Type | Description |
| --- | --- | --- |
| `report_id` | integer | Unique identifier of the report. Use it to track completion and export results. |

### Report output fields

| Field | Description |
| --- | --- |
| `Permalink`, `Name`, `Website` | Wokelo company identifier, display name and primary domain. |
| `HQ City`, `HQ Country`, `HQ Continent`, `Founded` | Headquarters location and founding year. |
| `Type`, `Operating Status` | Ownership type (`Public` or `Private`) and status (e.g. `Operating`, `Acquired`, `IPO`). |
| `Product Category`, `Core Offering`, `Product Catalog` | Primary product category, AI-generated description of the core business, and key products. |
| `Employees (Crunchbase)`, `Employees (LinkedIn)` | Headcount band and numeric headcount. |
| `Funding Stage`, `Total Funding`, `Last Funding Date`, `Key Investors` | Funding profile. Total funding is in USD. Typically empty for public companies. |
| `Revenue`, `EBITDA`, `Net Income`, `Market Cap`, `Enterprise Value`, `Ticker`, margins and multiples | Financial data in USD, primarily populated for public companies. |
| `Acquisitions`, `Investments` | Past acquisitions (with year) and notable investments. May be empty. |
| `Buyer Type` | `Strategic`, `Financial` or `Institutional`. |
| `Overall Score`, `Overall Score Rationale` | Composite strategic fit (1 to 10) and a one-sentence rationale. |
| `Deal Feasibility Score` | Whether the buyer can financially execute the deal. |
| `Product Synergy Score` | Product and capability overlap with the target. |
| `Deal Precedent Score` | Alignment with the buyer's historical M&A pattern and deal size. |
| `Synergy Potential Score` | Revenue and cost synergy opportunity. |
| `Commentary` | AI-written deal thesis covering rationale, synergies and risks. |

Each sub-score has a matching `... Rationale` field. AI scoring fields are present only where there is enough data for a reliable assessment. Unscored buyers are still returned with firmographic and financial data.
