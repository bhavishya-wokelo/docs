## 1. Overview

The Market Map API generates a long list of companies operating in a defined market, enriched with firmographic, funding and financial data. Given a market topic (e.g. _"warehouse automation"_) and optional filters, the AI pipeline evaluates each candidate against the market thesis and returns a list with relevance scores and per-company commentary.

This is an **asynchronous API**. Starting the workflow returns a `report_id`, which you use to track completion and export the results. See [How Async APIs work](/how-async-apis-work).

Each company includes firmographics, product profile, funding and headcount, financials (for public companies), M&A history, an `Overall Score` (1 to 10) and a `Commentary` explaining its relevance to the market.

**Common use cases:**

- **Deal sourcing**: build a scored target universe for a vertical or thesis
- **Corporate strategy and M&A**: map the landscape for a market entry or build-vs-buy analysis
- **Market research**: generate an exhaustive vendor set for benchmarking

## 2. Quick Start

**Step 1: Start the workflow**

<CodeGroup>

```bash cURL
curl --location 'https://api.wokelo.ai/api/workflow_manager/start/' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "warehouse automation",
    "workflow": "agentic_mm",
    "workbook_name": "warehouse automation",
    "advanced_settings": {
      "detailed_query": "warehouse automation",
      "companies": [],
      "company_type": "all",
      "geography": ["Worldwide"],
      "employee_count": [],
      "funding_stage": [],
      "total_funding_include_blanks": true
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.wokelo.ai/api/workflow_manager/start/",
    headers={
        "Authorization": "Bearer <YOUR_API_TOKEN>",
        "Content-Type": "application/json"
    },
    json={
        "topic": "warehouse automation",
        "workflow": "agentic_mm",
        "workbook_name": "warehouse automation",
        "advanced_settings": {
            "detailed_query": "warehouse automation",
            "companies": [],
            "company_type": "all",
            "geography": ["Worldwide"],
            "employee_count": [],
            "funding_stage": [],
            "total_funding_include_blanks": True
        }
    }
)
print(response.json()["report_id"])
```

</CodeGroup>

The response contains a `report_id`.

**Step 2: Track completion**

Use `/api/assets/get_notebook_status/` with the `report_id` to check whether the report has completed.

**Step 3: Export results**

Once the report is complete, use `/api/assets/download_report/` with the `report_id` to export the results.

## 3. Authentication

Include a Bearer token in the `Authorization` header of every request.

```text
Authorization: Bearer <YOUR_API_TOKEN>
```

Obtain a token from the `/auth/token/` endpoint using the client id and client secret under **Account Details → API Credentials** in the Wokelo dashboard. Contact [support@wokelo.ai](mailto:support@wokelo.ai) if you do not yet have API access.

<Warning>
  Never expose your token in client-side code or public repositories.
</Warning>

## 4. Request Reference

**Endpoint**

```text
POST https://api.wokelo.ai/api/workflow_manager/start/
```

The request body is JSON. Include `advanced_settings` in every request and send empty values (`""`, `[]`) for filters you do not want to apply.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `topic` | string | **Required** | The market or product category to map (e.g. `"warehouse automation"`). |
| `workflow` | string | **Required** | Must be `"agentic_mm"`. |
| `workbook_name` | string | **Required** | Name of the workbook that holds the generated report. |
| `advanced_settings` | object | Optional | Filter parameters. All filters below live inside this object. |
| `advanced_settings.detailed_query` | string | Optional | A more descriptive query that refines the market scope. |
| `advanced_settings.companies` | string[] | Optional | Permalinks or full URLs of representative companies to anchor the search. |
| `advanced_settings.geography` | string[] | Optional | `["Worldwide"]` for no restriction, or ISO country codes (e.g. `["USA", "GBR"]`). |
| `advanced_settings.company_type` | string | Optional | `"private"`, `"public"` or `"all"`. |
| `advanced_settings.employee_count` | string[] | Optional | Headcount bands. Empty array includes all. Values: `1-10`, `11-50`, `51-100`, `101-250`, `251-500`, `501-1000`, `1001-5000`, `5001-10000`, `10000+`. |
| `advanced_settings.founded_year` | object | Optional | Object with `from` and/or `to` (integer years, inclusive). |
| `advanced_settings.funding_stage` | string[] | Optional | Empty array includes all. Values: `Non-Equity Assistance`, `Angel round`, `Pre-seed`, `Seed`, `Series A` to `Series J`, `Corporate-Funded`, `Debt-Funded`, `Private equity round`, `Others`. |
| `advanced_settings.total_funding` | object | Optional | Object with `from` and/or `to`, in USD. |
| `advanced_settings.total_funding_include_blanks` | boolean | Optional | When `true`, companies with no reported total funding are included. |
| `advanced_settings.last_funding_round`, `.revenue`, `.ebitda`, `.net_income` | object | Optional | Each accepts `from` and/or `to`, in USD. Revenue, EBITDA and net income work best with `company_type: "public"`. |
| `advanced_settings.ev_ebitda` | object | Optional | Object with `from` and/or `to` (EV/EBITDA multiple). |

## 5. Response

### Workflow start response

```json
{
  "report_id": 117253
}
```

| Field | Type | Description |
| --- | --- | --- |
| `report_id` | integer | Unique identifier of the report. Use it to track completion and export results. |

### Report output fields

| Field | Description |
| --- | --- |
| `Permalink`, `Name`, `Website` | Wokelo company identifier, display name and primary domain. |
| `HQ City`, `HQ Country`, `HQ Continent`, `Founded` | Headquarters location and founding year. |
| `Type`, `Operating Status` | Ownership type (`Public` or `Private`) and status (e.g. `Operating`, `Acquired`, `IPO`). |
| `Product Category`, `Core Offering`, `Product Catalog` | Primary product category, AI-generated description of the core business, and key products. |
| `Employees (Crunchbase)`, `Employees (LinkedIn)` | Headcount band and numeric headcount. |
| `Funding Stage`, `Total Funding`, `Last Funding Date`, `Key Investors` | Funding profile. Total funding is in USD. Typically empty for public companies. |
| `Revenue`, `EBITDA`, `Net Income`, `Market Cap`, `Enterprise Value`, `Ticker`, margins and multiples | Financial data in USD, primarily populated for public companies. |
| `Acquisitions`, `Investments` | Past acquisitions (with year) and notable investments. May be empty. |
| `Overall Score`, `Commentary` | Relevance score (1 to 10) for the queried market, and an AI-written explanation of the fit. |
