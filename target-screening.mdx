## Overview

The Target Screening API generates a long list of potential acquisition targets for a given acquirer, enriched with structured data. You can refine the output with a detailed query, sample companies, geography, company type, employee count, funding stage, financial filters, and more.

Target Screening runs as a workflow. Set `workflow` to `target_screening_v2` in the request body to start one. The request returns a `report_id`, which you then use to track completion and export the results.

## Endpoint Details

- Method: POST
- Endpoint: `/api/workflow_manager/start/`

## Authentication Requirements

- Include a valid JWT token in your request header
- If you don't have a token yet, you can get one from the `/auth/token/` endpoint first.

## Request

#### Header Parameters

<ParamField header="Authorization" type="string" required>
  JWT token obtained from the Authentication request
</ParamField>

### Body Parameters

<ParamField body="topic" type="string" required>
  The sector or theme in which to screen for targets (e.g. `"Enterprise Software Solutions"`)
</ParamField>

<ParamField body="workflow" type="string" required>
  The workflow to run. Must be `"target_screening_v2"` for Target Screening.
</ParamField>

<ParamField body="workbook_name" type="string" required>
  Name of the workbook that will hold the generated target list (e.g. `"Enterprise Software Solutions"`)
</ParamField>

<ParamField body="advanced_settings" type="object" required>
  Acquirer and filter parameters object. Include the object in every request, and send empty values (`""`, `[]`) for any filter you do not want to apply.

  <ParamField body="acquirer" type="string" required>
    Permalink of the acquiring company or its complete URL (e.g. `"microsoft"` OR `"https://www.microsoft.com/"`)
  </ParamField>

  <ParamField body="detailed_query" type="string">
    A descriptive query to refine the target search scope
  </ParamField>

  <ParamField body="companies" type="string[]">
    Permalinks of representative companies or their complete URLs to anchor the target search.
  </ParamField>

  <ParamField body="geography" type="string[]">
    Geographic scope. Pass `["Worldwide"]` for no geographic restriction, or a list of ISO country codes (e.g. `["USA", "GBR"]`).
  </ParamField>

  <ParamField body="company_type" type="string">
    Type of company to include. Accepted values: `"private"`, `"public"`, `"all"`
  </ParamField>

  <ParamField body="employee_count" type="string[]">
    Filter by employee headcount range. Pass an empty array to include all headcounts.

    Supported array values: `1-10`, `11-50`, `51-100`, `101-250`, `251-500`, `501-1000`, `1001-5000`, `5001-10000`, `10000+`
  </ParamField>

  <ParamField body="founded_year" type="object">
    Filter by company founding year.

    <ParamField body="from" type="integer">
      Minimum founding year (inclusive), e.g. `2010`
    </ParamField>

    <ParamField body="to" type="integer">
      Maximum founding year (inclusive), e.g. `2020`
    </ParamField>
  </ParamField>

  <ParamField body="funding_stage" type="string[]">
    Filter by funding stage. Pass an empty array to include all stages.

    Supported array values: `Non-Equity Assistance`, `Angel round`, `Pre-seed`, `Seed`, `Series A`, `Series B`, `Series C`, `Series D`, `Series E`, `Series F`, `Series G`, `Series H`, `Series I`, `Series J`, `Corporate-Funded`, `Debt-Funded`, `Private equity round`, `Others`
  </ParamField>

  <ParamField body="total_funding" type="object">
    Filter by total funding amount raised (in USD).

    <ParamField body="from" type="number">
      Minimum total funding in USD, e.g. `1000000`
    </ParamField>

    <ParamField body="to" type="number">
      Maximum total funding in USD, e.g. `50000000`
    </ParamField>
  </ParamField>

  <ParamField body="total_funding_include_blanks" type="boolean">
    When `true`, companies with no reported total funding are included in the results alongside companies that match the `total_funding` range.
  </ParamField>

  <ParamField body="revenue" type="object">
    Filter by annual revenue (in USD).

    <ParamField body="from" type="number">
      Minimum annual revenue in USD, e.g. `500000`
    </ParamField>

    <ParamField body="to" type="number">
      Maximum annual revenue in USD, e.g. `10000000`
    </ParamField>
  </ParamField>
</ParamField>

<RequestExample>

### Response

A successful response returns a `report_id` that identifies the target screening report.

#### Successful Response Fields

<ResponseField name="report_id" type="integer">
  Unique identifier for the report created by this request. Use it to track completion and to download the results (see below).
</ResponseField>


<ResponseExample>

```json 200
{
  "report_id": 117253
}
```

</ResponseExample>

## Tracking Completion and Exporting Results

Target Screening generation is asynchronous. After you receive a `report_id`:

1. Use `/api/assets/get_notebook_status/` to track completion of the report.
2. Once the report is complete, use `/api/assets/download_report/` to export the results.
