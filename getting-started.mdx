## Authentication

All API requests must be authenticated using a JWT token. Follow the steps below to generate your token:

- Use the authentication endpoint: `https://api.wokelo.ai/auth/token/`
- Use the Client ID and Client Secret from the API Credentials page, along with your email and password. Set the grant type to `"password"`.
- The response contains your JWT token. Pass it in the `Authorization` header of every request as `Bearer <YOUR_API_TOKEN>`.

<CodeGroup>

```bash cURL wrap
curl --location 'https://api.wokelo.ai/auth/token/' \
--form 'username="sam@abconsulting.com"' \
--form 'password="password"' \
--form 'grant_type="password"' \
--form 'client_id="YOUR_CLIENT_ID"' \
--form 'client_secret="YOUR_CLIENT_SECRET"'
```

```python Python expandable wrap
import requests

url = "https://api.wokelo.ai/auth/token/"

payload = {
    'username': 'sam@abconsulting.com',
    'password': 'password',
    'grant_type': 'password',
    'client_id': 'YOUR_CLIENT_ID',
    'client_secret': 'YOUR_CLIENT_SECRET'
}
files = []
headers = {}

response = requests.request("POST", url, headers=headers, data=payload, files=files)

print(response.text)
```

</CodeGroup>

## Make your first API call

Let's try the Market Map API. Wokelo APIs are asynchronous: you start a workflow, track its status, and then download the report. See [How Async APIs work](/how-async-apis-work) for details.

### Step 1: Start the workflow

<CodeGroup>

```bash cURL
curl --location 'https://api.wokelo.ai/api/workflow_manager/start/' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --data '{
    "topic": "warehouse automation",
    "workflow": "agentic_mm",
    "workbook_name": "warehouse automation",
    "advanced_settings": {
      "detailed_query": "warehouse automation",
      "companies": [],
      "company_type": "all",
      "geography": ["Worldwide"],
      "employee_count": [],
      "funding_stage": [],
      "total_funding_include_blanks": true
    }
  }'
```

```python Python wrap
import requests

response = requests.post(
    "https://api.wokelo.ai/api/workflow_manager/start/",
    headers={
        "Authorization": "Bearer <YOUR_API_TOKEN>",
        "Content-Type": "application/json"
    },
    json={
        "topic": "warehouse automation",
        "workflow": "agentic_mm",
        "workbook_name": "warehouse automation",
        "advanced_settings": {
            "detailed_query": "warehouse automation",
            "companies": [],
            "company_type": "all",
            "geography": ["Worldwide"],
            "employee_count": [],
            "funding_stage": [],
            "total_funding_include_blanks": True
        }
    }
)
report_id = response.json()["report_id"]
print("Report started:", report_id)
```

</CodeGroup>

A successful request returns a `report_id`:

```json
{
  "report_id": 117253
}
```

### Step 2: Check the report status

Use the `report_id` to track completion with `/api/assets/get_notebook_status/`.

```bash
curl --request GET \
  --url 'https://api.wokelo.ai/api/assets/get_notebook_status/?report_id=117253' \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>'
```

```json
{
  "report_id": 117253,
  "status": "Completed",
  "title": "warehouse automation"
}
```

### Step 3: Download the report

Once the status is `Completed`, export the results with `/api/assets/download_report/`. Set `file_type` to `pdf`, `docx` or `json`.

```bash
curl --request POST \
  --url https://api.wokelo.ai/api/assets/download_report/ \
  --header 'Authorization: Bearer <YOUR_API_TOKEN>' \
  --header 'Content-Type: application/json' \
  --output report.pdf \
  --data '{
    "report_id": 117253,
    "file_type": "pdf"
  }'
```
